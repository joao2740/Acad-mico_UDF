# Academic UDF

> 📚 Projeto acadêmico desenvolvido para a Universidade de Distrito Federal

## 📋 Descrição

Projeto educacional com foco em desenvolvimento web e tecnologias frontend, criado como parte de atividades acadêmicas na UDF.

## 🛠️ Tecnologias

- **HTML5** - Estrutura
- **CSS3** - Estilização
- **JavaScript** - Interatividade

## 📁 Estrutura do Projeto

```
├── index.html
├── styles/
│   └── style.css
├── scripts/
│   └── script.js
└── assets/
```

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/joao2740/Academic-UDF.git
```

2. Abra o arquivo `index.html` no seu navegador
